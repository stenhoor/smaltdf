# smaltdf brand assets

Copied from [`stenhoor/smalt-brand`](https://github.com/stenhoor/smalt-brand) `logos/smaltdf/` (commit `76386bb`).
Don't edit them here: change them in smalt-brand and copy them again.

**Small. Alternative. Frames.** Dataframes for smaltdb. Small and fast. smaltdf is a language, so its colour is the
language layer's cobalt magenta (`#B0249F`; text `#981C89`, on dark `#F57FE6`). `alt` stays smalt `#003399`.

| File | Use |
| --- | --- |
| `lockup.svg` / `lockup-on-dark.svg` | Axes mark + wordmark. The docs nav. |
| `wordmark.svg` / `wordmark-on-dark.svg` | Wordmark alone. |
| `axes-mark.svg` / `axes-mark-on-dark.svg` | The Axes mark alone. The docs hero. |
| `app-icon.svg` | App icons, social avatars. |
| `favicon-32.svg`, `favicon-16.svg` | Browser tabs. |

The `-on-dark` files are transparent with light ink: they are for dark backgrounds only and look blank in light previews.

The stage badge (`work-in-progress.svg`, `-on-dark`) and the family badge (`a-smaltworks-project.svg`, `-on-dark`) are
copied from smalt-brand `badges/` (commit `3ee6e11`), for the site.
